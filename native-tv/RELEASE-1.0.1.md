# MDKTV 1.0.1：低存储修复

修复 1.0 首次启动强制下载完整曲库数据库、电视空间不足时无法进入应用的问题。

- 启动只检查已有本地曲库，不自动下载或更新完整数据库。
- 没有数据库也能进入主界面，选择本地歌曲、U盘或自己的网络曲库。
- 完整数据库改为确认后按需下载，失败后可继续使用应用，不删除原有曲库。
- 导入网络曲库 JSON 后，HTTP(S) 媒体直接在线播放，不要求先下载整首到电视。仅支持自己有权访问的有效媒体地址，实际格式兼容性取决于电视播放器。

版本号 1.0.1（versionCode 16），应用 ID org.mdktv.nativeapp。使用与 1.0 相同的发布密钥，可直接覆盖安装，无需卸载。

注意：这不会凭空提供在线曲库。完整数据库未安装时，依赖该数据库的排行榜/歌星等页面没有相应数据；网络点歌需要自行配置合法的网络曲库地址。旧数据库歌曲的下载播放方式保留。自动清理缓存和任何媒体删除均不是本次升级的必要步骤。

包含 6 项启动/下载回退测试、5 项网络播放路由测试及原有测试。电视实机播放仍需验收。
