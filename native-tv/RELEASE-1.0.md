# MDKTV 1.0 初始版

下载下方 Assets 中的 **MDKTV-1.0.apk**，在 Android 电视或电视盒子上安装。

- Android 5.0+，支持 ARMv7 / ARM64；应用 ID `org.mdktv.nativeapp`。
- APK 内版本号 1.0，内部版本代码 15；使用固定的 MDKTV 发布密钥签名，非调试 APK。
- 包含原生电视界面、遥控器导航、IJK 播放、原唱/伴唱控制、手机话筒接收和基础演唱评分。
- 构建前检查原生动态库依赖，并运行 31 项原有 JVM 单元测试。

初始版尚未对接 NAS / Node 服务的曲库、登录和队列；请使用自己的合法媒体。手机话筒、HTTPS 证书信任和实际电视播放仍需实机验证。评分依据人声覆盖、音高稳定性和响度，没有歌曲标准旋律比对；未实现 USB 麦克风的独立低延迟返听链路。

此前 `.qa` 调试包与本次正式应用 ID 不同，可以并存；本版不会自动迁移调试包数据。更新正式版本时请使用同一发布密钥。

源码随本标签提供，来源与集成说明见 `native-tv/INTEGRATION.md`。基于麦动 KTV，原作者杨家三郎，原项目 https://github.com/coolwuzizai/maidong-ktv；原生工程来自 jimi10000/maidong-ktv。保留原协议和署名，完全免费、禁止商用；第三方组件遵循各自许可。
